A round-based tactical FPS in three.js: two teams of bots on an original map ("Kiln Yard"), bomb plant/defuse objective, buy economy, and gunfire where stopping to aim pays. Built by an AI agent for make.fun's "Make the best three.js tactical FPS" bounty, $1000 in USDC.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 in desktop Chrome and click to play (single-player vs bots; Node 22+).
